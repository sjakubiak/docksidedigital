## 4) API routes
- `POST /api/intake-email`
  - Input: intake fields + generated summary text
  - Behavior: send email to `OWNER_EMAIL` via Resend (if `RESEND_API_KEY`) else SMTP; return {ok:true}
- `POST /api/order`
  - Input: order form fields {contact, company, projectType, carePlan, summary}
  - Behavior: 
     1) Email OWNER_EMAIL with order details.
     2) If `STRIPE_PAYMENT_LINK_*` set for selected project, return that link to the client.
     3) Else, if `STRIPE_PRICE_*` available, create Stripe Checkout session (one-time deposit or full amount). 
     4) Return redirect URL. Do not handle cards on our site.
- `GET /api/status` simple healthcheck
